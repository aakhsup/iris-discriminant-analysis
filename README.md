# Iris: Дискриминантный анализ и классификация

Лабораторная работа по статистическому анализу и классификации датасета **Iris** (ирисы Фишера). Реализованы корреляционный анализ, линейный дискриминантный анализ (LDA) и сравнение четырёх алгоритмов классификации: LDA, SVM, логистическая регрессия и наивный байесовский классификатор.

---

## 📖 О проекте

Цель работы — исследовать структуру датасета Iris, оценить степень сопряжённости признаков и сравнить несколько алгоритмов классификации на паре классов **setosa** и **versicolor**.

### Что реализовано

| № | Задача | Инструменты |
|---|--------|-------------|
| 1 | Загрузка библиотек и данных | `pandas`, `numpy`, `sklearn`, `seaborn` |
| 2 | Табличная статистика по датасету | `DataFrame.describe`, `value_counts` |
| 3 | Визуализация по парам признаков | `matplotlib`, `seaborn` (scatter + hist/KDE) |
| 4 | Корреляционный анализ (Pearson) | `DataFrame.corr` + heatmap |
| 5 | LDA: решающая функция и зоны | `LinearDiscriminantAnalysis` |
| 6 | Совмещение LDA и линейной регрессии | `LinearRegression` |
| 7 | Сравнение LDA / SVM / LogReg / Naive Bayes | классификаторы `sklearn` |
| 8 | Оценка качества: матрица ошибок, ROC, AUC | `confusion_matrix`, `roc_curve`, `auc` |

---

## 📊 О датасете

**Iris** — классический датасет для задач классификации (Фишер, 1936).

- **Объекты:** 150
- **Признаки:** 4 количественных
  - `sepal_length` — длина чашелистика
  - `sepal_width` — ширина чашелистика
  - `petal_length` — длина лепестка
  - `petal_width` — ширина лепестка
- **Классы (по 50 объектов):** `setosa`, `versicolor`, `virginica`
